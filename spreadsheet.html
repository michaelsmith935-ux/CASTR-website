CASTR Spreadsheet 74.0.0.xlsm — macro-enabled Excel workbook (.xlsm)

Version 74.0.0 • approx. 8.6 MB • Free • Windows desktop Excel (32-bit or 64-bit)

⬇ Download Free

CASTR Spreadsheet runs a Monte Carlo cost and schedule risk simulation entirely inside Excel. You document the project, structure the estimate, enter base uncertainty and a quantified risk register, then run the simulation to get confidence-based (P-level) budgets, contingency by source, year-of-expenditure conversion, sensitivity and tornado analysis, tail drivers, what-if testing and a joint cost–schedule confidence chart. It follows the same FHWA NHI Course 134205 methodology as the CASTR application.

Requirements & Notes

  • Microsoft Excel for Windows (desktop) with macros enabled. Works with both 32-bit and 64-bit Excel.
  • Not compatible with the Bluebeam Excel add-in while it is active — disable it before opening.
  • Use only one active CASTR workbook at a time.
  • Run the tool directly from the worksheets or from the CASTR add-in menu and Switchboard.
  • Color coding on the About sheet identifies user inputs, CASTR outputs, calculated values, QC checks and errors.

Getting Started

  1. Download the workbook using the button above and save it to a local folder (not a network or cloud-synced location the first time you open it).
  2. Unblock the file. Windows marks files downloaded from the internet and Excel will silently disable their macros. Right-click the .xlsm file → Properties → check Unblock → OK.
  3. Open in Excel and click Enable Content when prompted, then read and accept the Disclaimer sheet.
  4. Work the sheets in order — Home → Names → Inflation → Structured Estimate → Base Uncertainty → Risk Identification → Risk Register → Simulation Settings — then run the simulation and review the results sheets.
  5. Learn more: the User Manual and the Video Library cover the same methodology and workflow used in the workbook.
Pre-simulation checks. The Simulation Settings sheet runs QC checks (risk costs and schedules assigned, Risk ID synchronized with the Risk Register, base uncertainty complete) and flags any that are not OK before you run the simulation.

Input Sheets

HOME

Home

Project information, review dates, team roles, project complexity and the AASHTO sliding-scale contingency range for your % design completion.

NAME

Names

Define project segments, phases (PE, RW, CN, UT, etc.), inflation-table assignments and risk categories.

INFL

Inflation

Compound inflation tables by phase with cumulative year/month factors used for year-of-expenditure (YOE) conversion.

EST

Structured Estimate

Roll the sponsor's estimate into cost phases: base cost, traditional contingency, prior and fixed costs, inflation point and dates.

BASE

Base Uncertainty

Base variability and market-condition ranges by phase-segment, plus the schedule duration analysis that feeds the simulation.

ADJ

Adjustments

Track pre-review vs. post-review estimate changes line by line with an audited net-adjustment total.

RID

Risk Identification

Workshop capture sheet: category, phase-segment impacted, description, response, dependency and probability. Syncs to the register.

REG

Risk Register

Quantified cost and schedule impacts (min / most likely / max), risk status, dependencies and parent/prerequisite probability logic.

MIN

Minor Risks

Aggregate small risks below a mean-value threshold so they are carried without cluttering the register.

LINK

Predecessor Links

Phase-segment predecessor/successor links with lag so schedule delays propagate downstream.

CORR

Correlation

Rank-correlation editor for one-to-many pairs with automatic matrix validity (positive-definite) checking.

SIM

Simulation Settings

Toggle base variability, market conditions and the register; set iterations, random seed, convergence monitoring, percentiles and budget confidence.

Results & Analysis Sheets

YOE

Year of Expenditure

Base cost, register cost and delay by phase-segment in current-year and YOE dollars, with confidence-based budgets.

SUM

Summary

P-level total project cost, contingency in $ and %, P10/P90 spread, COV, and a check against the national contingency range.

SCEN

Scenarios

Layered results: base cost + base variability, + market conditions, + risk register, in CY and YOE, with contingency by source.

DIST

Distributions & Histogram

PDF/CDF bins for every output, plus a presentation-ready results chart.

SENS

Sensitivity

Spearman rank correlation, variance share and top-driver share for each output.

TORN

Tornado

Tornado charts of the top risk drivers, selectable by output.

RANK

Risk Rank

Cost and schedule threats and opportunities ranked by expected value.

TAIL

Tail Drivers

Which risks fire in the favorable (lower 10%) and adverse (upper 10%) tails, with excess contribution.

WHAT

What-If Sensitivity

Deactivate risks one at a time and watch live contingency and P-level cost respond.

JC

Joint Confidence

YOE cost vs. completion-date scatter with 80/90% contours, marginal P-levels and joint coverage.

USER

User-Defined Outputs

Add any cell or formula as a tracked simulation output and it appears in every results sheet.
